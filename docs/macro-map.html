Wavetable conversion

How a photo becomes the oscillator's waveform. Two readings of the same object: the shape, read column by column, and the texture, read ring by ring in its 2D spectrum. Scroll inside each panel to run its steps; the wavetable then morphs from one to the other.

photo + SAM mask→shape: columns → 64 harmonics+texture: rings → 64 harmonics→32 frames

Macro implementation

Every preset starts as a photo and the object's SAM mask. Six measurements are taken, each is mapped to 0–1 with a fixed range, and each macro then turns its own synth parameters. Turn a macro knob (drag, scroll or arrow keys) and watch what follows, or load one of the example objects.

photo + SAM mask→measurement→fixed range → 0–1→macro→synth parameters

The wavetable · 32 frames

Each frame mixes the two spectra harmonic by harmonic, always with the shape's phases, so the middle frames never cancel out. The synth's frame knob scans these.

Load an object
Measurements and their ranges come from CV/macros.py (MACRO_RANGES); curves and thresholds from CV/macro_mapping.py. The objects are dataset photos, the same ones as the presets in dataset-presets/. Parameters a macro does not touch keep the synth's init values.

Try your own
